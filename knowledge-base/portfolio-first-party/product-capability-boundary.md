# 小智作品集：产品形态与能力边界

资料性质：作品集首方公开说明。负责人为小智作品集作者，版本为 2026.08.2，自 2026-08-12 起生效。

小智采用微信小程序式视觉和交互，但交付物是最大宽度 430px、部署在 Vercel 的 Next.js 移动端 Web，不是可提交微信审核的原生小程序。桌面浏览时画布居中，五个主页面共用同一底部导航。

Production Live 已接入 Supabase、百炼千问、高德 Web 服务和 2024-11 历史房源。Supabase 保存结构化数据、会话、工具审计、反馈和经授权的长期偏好；千问负责理解用户意图、选择工具和组织回答；高德负责地理编码、周边地点和步行路线。AI 不能替代这些事实来源。

房源属于经授权使用的历史记录；团购、线上超市、库存和交易流程仍是明确标注的演示业务数据，不产生真实交易。外部服务未配置、超时或无结果时，界面必须显示降级状态，不能把模拟结果偷偷伪装成真实接入。

## 常见问题

小智展示的是原生微信小程序吗，它目前有哪些真实接入和演示边界？不是。它是 430px 的 Next.js 移动端 Web；Supabase、百炼千问、高德和历史房源属于 Live 接入，团购、线上超市、库存和交易仍是演示业务。

Production Live 已经接通了哪些外部服务？已接通 Supabase、百炼千问、高德 Web 服务和 2024-11 历史房源。

团购和线上超市会产生真实交易吗？不会，它们是明确标注的演示业务数据。

外部服务超时后能否偷偷返回模拟结果？不能，必须显示降级或未核验状态。
