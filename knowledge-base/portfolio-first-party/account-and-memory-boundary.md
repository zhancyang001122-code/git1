# 小智作品集：账号与长期偏好边界

资料性质：作品集首方公开说明。负责人为小智作品集作者，版本为 2026.08.2，自 2026-08-13 起生效。

游客可以浏览公开页面并体验匿名对话，不需要先注册。匿名会话使用受签名保护的浏览器 Cookie 维持会话身份，但游客不能把长期偏好写入某个云端账号；公开浏览、匿名对话和云端长期记忆不是同一件事。

面试演示不发送邮箱或短信验证码。登录页公开提供固定演示码 `666666`，服务端将它映射到一个隔离、共享的 Supabase 演示账号；真实随机密码只保存在 Vercel Sensitive 环境变量，浏览器不会收到账号凭据。该流程已在 Production 完成真实 Supabase Session、RLS 偏好写入、退出、重登、跨会话读取和最终清理验收。它是低频作品集取舍，不是面向真实用户的生产级认证。

登录只建立当前浏览器会话，不会自动开启长期记忆，也不会自动把一次性聊天需求保存为长期偏好。由于演示账号由所有体验者共享，体验者不得填写真实隐私，离开前应关闭长期记忆并删除演示偏好。

用户明确要求长期记住时，千问只能生成一条无副作用的偏好提案。只有已登录用户在界面点击确认后，Preferences API 才通过 Supabase RLS 写入本人数据；点击取消必须零写入。关闭长期记忆会删除该账号保存的整行偏好，单纯退出登录不会删除已经授权保存的云端偏好。

## 常见问题

游客、登录和长期偏好在小智中分别是什么关系？游客可浏览和匿名对话；登录建立浏览器会话；长期偏好还需要用户单独确认授权。

游客不注册可以使用什么功能？可以浏览公开页面并体验匿名对话，但不能把长期偏好写入云端账号。

登录后会自动开启长期记忆并保存聊天吗？不会，登录本身不等于授权长期记忆。

Production 使用什么登录方式，是否已经验收？使用公开固定演示码 `666666` 进入共享的隔离 Supabase 演示账号；真实 Session、RLS 偏好、退出、重登和清理已完成 Production 验收，但它不等于生产级用户认证。

为什么不把固定演示码称为真实验证码？因为系统不会向某个可验证身份发送验证码，任何体验者都能使用同一个公开演示码；它只能证明作品集的 Session 与 RLS 链路，不证明真实用户身份。

长期偏好什么时候才会写入云端，退出会删除吗？已登录用户点击确认后才通过 RLS 写入；退出登录不会删除，关闭长期记忆才会删除整行偏好。
