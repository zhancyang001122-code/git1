# Phase 8：知识沉淀、审核与评测

执行实施计划 Task 10。

实现受控知识闭环：

- 触发：low confidence、no result、点踩、纠错、重复追问、人工答案。
- 创建 `knowledge_candidates`，保存脱敏问题、原因和已有证据。
- 知识运营页：队列、候选详情、AI 草稿、证据、审核决策、发布。
- 发布创建新 article version，不覆盖历史；调用数据库发布函数。
- 发布后切片和 embedding，索引成功才进入线上检索。
- 自动运行相关 eval cases；失败则显示风险，不静默宣称上线成功。
- 用户对话永远不能直接写入 published 知识。

演示必须支持：第一次问过期两天退款 → 无依据兜底并形成候选 → 人工补充审核 → 发布/索引 → 第二次带引用回答。
