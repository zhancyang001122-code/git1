# AI 模型性能与成本 SLO

## 指标定义

- 首 Token：服务器收到 `/api/chat` 请求，到首次生成用户可见 `assistant_delta` 的毫秒数；不包含浏览器渲染和公网最后一跳。
- 首 Token P95：24 小时窗口中上述时延的离散 95 分位，至少 20 个有文本输出的回答；超过 6000ms 告警。
- 单会话成本：每轮千问请求按自己的输入 Token 匹配公开价格档，再汇总到回答和会话；至少 5 个会话、且窗口内所有会话完整计价时，最高估算超过 0.1 元告警。

## 数据可信度

- 首 Token 只在真正生成回答文本时记录；仅工具调用而没有文本不算样本。
- 任一模型轮次缺输入或输出 Token，整次回答不写估算成本。
- 每条有成本的助手消息同时保存 `pricing_effective_from`，避免未来价格变更后失去口径。
- 成本明确标记为估算，不冒充百炼账单；窗口内存在部分覆盖时状态为“覆盖不足”，不是“正常”。

## 安全边界

- 新列仍位于原本受 RLS 保护的 `conversation_messages`，浏览器不能跨会话读取。
- 告警 RPC 只返回聚合数值、阈值、样本量和固定说明，不返回对话正文或结构化结果。
- 两个新信号复用事故幂等、认领、解决、自动恢复和不可变事件审计。
