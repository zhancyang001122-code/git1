# Task 9 — 多工具对话、上下文记忆与可解释结果

## 完成范围

- 新增有界上下文构建器：系统规则、历史摘要、最近 12 条消息与经校验的页面上下文分层注入。
- 页面上下文统一标记为不可信参考，只能作为检索线索，不能覆盖系统规则。
- 新增确定性对话摘要，过滤工具消息和常见密钥字段；超过 12 条消息后可更新 `conversation_sessions.summary`。
- 新增当前轮偏好合并规则：当前轮显式条件优先，但不修改长期保存值。
- 工具结果进入模型前执行白名单摘要，只保留结构化卡片 ID、公开事实、必要知识片段和稳定错误信息，不传递原始数据库行或完整高德响应。
- Demo 多工具链支持按依赖执行 `search_houses -> search_nearby_places -> search_knowledge`。
- 对话 UI 展示公开处理步骤、结构化结果、知识引用、版本、生效日期和“模拟知识资料”标签。
- 调试摘要仅在显式开启时展示工具名、脱敏参数摘要、来源、结果数、耗时和错误码。
- Demo 警告明确说明房源、团购、商品、地图和知识均为模拟数据，且未连接 Supabase、高德或千问。
- Playwright 端口支持通过 `PLAYWRIGHT_PORT` 隔离，避免打断已有本地预览。
