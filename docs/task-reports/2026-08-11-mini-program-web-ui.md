# 微信小程序式 Web UI 改造报告

## 目标

在不改变 Next.js、Supabase、Agent、Maps 和 Knowledge 分层的前提下，将全站统一为“微信小程序结构 × 小智蓝紫品牌”的 430px 移动端 Web 演示，并保留真实来源、Demo 边界、失败降级和可访问性。

## 已完成

- 五个主页面统一使用 48px 顶栏、功能胶囊、扁平五栏底部导航和 safe area。
- 首页、小智、推荐、消息、我的完成紧凑化重排；删除“以后再接入”式伪完成文案。
- 新增可访问的 `ActionSheet`、`Toast`、`ConfirmDialog` 和 `CellGroup`，支持 Esc、焦点管理和 44px 触控目标。
- 房源筛选和排序改为底部弹层；历史房源与演示房源继续显示明确来源。
- 团购、超市、购物车、周边和知识运营统一视觉与反馈；加购、收藏使用 Toast，清空购物车和知识审核使用确认弹窗。
- 周边定位只在用户主动点击后请求权限；定位拒绝回退武林广场；地图失败可以局部重试。
- 360px、390px、430px 画布均无横向溢出；横向筛选保留触摸滚动但隐藏桌面滚动条。

## 专业修正

早期设计文档将搜索框写为 40px，但同时要求触控目标至少 44px。两者冲突，因此实现与文档统一修正为 44px，没有为了截图相似度降低可访问性。
