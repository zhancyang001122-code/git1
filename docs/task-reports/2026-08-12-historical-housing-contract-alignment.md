# 2024 历史房源契约对齐报告

## 结论

有效产品契约、Agent 工具、页面筛选、用户偏好与演示文案已对齐到现有 2024 房源数据能够可靠支持的字段。项目不再把区域筛选、实时可租状态、地铁距离或其他未被历史数据证明的字段包装成已接通能力。

## 本轮变更

- `search_houses` 只接受城市、价格、租住类型或户型、附近地点和数量上限。
- Live 模式优先使用 Supabase 历史房源 Adapter；显式配置时才使用本地 HTTP Adapter。
- 历史字段缺失时返回 `null` 或“暂无记录”，不由 Agent 补造。
- 房源卡明确展示历史数据来源和 `2024-11` 数据周期，不声称当前仍可出租。
- 用户偏好、知识查询、演示场景和页面筛选删除与作品主线无关的专项逻辑。
- OTP E2E 改为忽略 Mailpit 中旧邮件，避免误取已经使用过的验证码。
