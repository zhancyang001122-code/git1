# 页面规格

## 全局小程序式外壳

- 所有页面运行在最大 430px 的 Web 画布中，不模拟假的系统状态栏。
- 主页面使用居中标题和右侧功能胶囊；二级页面增加左侧返回。
- 五个主页面复用扁平 `BottomNavigation`，中央小智按钮不上浮。
- 筛选、排序和定位方式优先使用底部 `ActionSheet`。
- 收藏、购物车和保存偏好使用 Toast；危险操作使用确认弹窗。
- 蓝紫色是小智品牌色，绿色只表达成功状态。

## 首页 `/`

参考 `01-home.png`：

1. 定位栏
2. 全局搜索，提交后进入小智
3. 小智欢迎卡和快捷问题
4. 租房、团购、超市、周边入口
5. 附近精选混合卡片
6. 小智推荐横条
7. 统一扁平底部导航

## 推荐 `/discover`

参考 `02-discover.png`：

- 定位、搜索、分类
- 双列社区卡片
- 封面、分类、标题、位置、作者、收藏数
- “问问小智”携带帖子上下文
- 内容全部可以是明确标记的 Mock

## 小智欢迎页 `/xiaozhi`

参考 `03-xiaozhi-home.png`：

- 小智标题和地点
- 欢迎大卡
- 五个快捷任务
- 推荐问题和换一批
- 固定 ChatComposer
- 顶部使用小程序式标题栏和功能胶囊

## 对话 `/xiaozhi/chat`、`/xiaozhi/chat/[conversationId]`

参考 `04-xiaozhi-chat.png`：

消息类型：

- 用户文本
- 小智流式文本
- 工具进度
- 房源/团购/商品/POI 卡片
- 知识来源
- 错误、重试和追问建议

能力：

- SSE、取消、重试、刷新恢复
- 多轮工具
- 点赞、点踩、纠错
- 调试面板
- 用户消息使用右侧气泡；小智文本、工具进度、结果卡和引用分层展示

## 房源 `/houses`、`/houses/[id]`

参考 `05-houses.png`：

筛选：位置、户型、租金、排序。
卡片：图、标题、面积、朝向、楼层、位置、租金、标签、收藏、问小智。  
详情：历史字段、数据来源、周边、地图、预约演示。

## 团购 `/deals`、`/deals/[id]`

参考 `06-deals.png`：

分类、双列卡片、价格、折扣、距离、销量、退款/预约标签。  
详情显示套餐、门店、有效期、规则引用和模拟购买。

## 超市 `/market`

参考 `07-market.png`：

Banner、分类、筛选、商家块、横向商品、库存、配送、配菜助手、购物车。结算为显式模拟流程。

## 消息 `/messages`

参考 `08-messages.png`：

全部、系统、小智、互动。支持未读和跳转上下文。

## 我的 `/me`

参考 `09-profile.png`：

用户信息、收藏、浏览、订单、地址、对话历史、预算/区域/交通/饮食偏好、知识反馈、帮助设置。

## 知识反馈 `/me/feedback`

选择关联消息、错误类型、纠正建议和证据。提交到 `ai_feedback`，满足规则时创建候选知识。

## 知识运营 `/knowledge-admin`、`/knowledge-admin/[id]`

Demo Admin 专用：

- 候选列表
- 对话、当前知识、AI 草稿
- 审核、驳回、编辑、发布
- embedding 状态
- 回归评测结果

生产版本需独立后台和 RBAC。
