# 页面规格

## 全局小程序式外壳

- 所有页面运行在最大 430px 的 Web 画布中，不模拟假的系统状态栏。
- 主页面使用居中标题和右侧功能胶囊；二级页面增加左侧返回。
- 五个主页面复用扁平 `BottomNavigation`，中央小智按钮不上浮。
- 筛选、排序和定位方式优先使用底部 `ActionSheet`。
- 收藏、购物车和保存偏好使用 Toast；危险操作使用确认弹窗。
- 蓝紫色是小智品牌色，绿色只表达成功状态。

## 首页 `/`

参考 `01-home.png`：

1. 定位栏
2. 全局搜索，提交后进入小智
3. 小智欢迎卡和快捷问题
   - 主卡只保留一个“问问小智”主操作，直接携带主演示问题进入对话
4. 租房、团购、超市、周边入口
5. 附近精选混合卡片
6. 小智推荐横条
7. 统一扁平底部导航

定位栏必须可点击并打开“选择位置” ActionSheet。用户可以在主动操作后授权浏览器定位，也可以输入城市和地点手动选择。选中的查询中心保存在当前浏览器，并由首页、房源、团购、超市、周边和小智共用；用户在问题中明确输入其他地点时，明确输入优先。高德 POI 使用 GCJ-02 坐标，历史房源距离使用 WGS84 坐标，禁止混用。

## 小智欢迎页 `/xiaozhi`

参考 `03-xiaozhi-home.png`：

- 小智标题和地点
- 欢迎大卡
- Live 模式不展示面试说明条；Demo 模式仍必须明确标注模拟边界

- 推荐问题和换一批

## 对话 `/xiaozhi/chat`、`/xiaozhi/chat/[conversationId]`

参考 `04-xiaozhi-chat.png`：

消息类型：

- 用户文本
- 小智流式文本
- 工具进度
- 房源/团购/商品/POI 卡片
- 知识来源
- 错误、重试和追问建议

能力：

- SSE、取消、重试、刷新恢复
- 多轮工具
- 点赞、点踩、纠错
- 调试面板
- 用户消息使用右侧气泡；小智文本、工具进度、结果卡和引用分层展示
- 房源、团购、商品结果卡进入对应详情；POI 结果卡直接打开高德步行导航，不保留无响应的装饰卡片

## 房源 `/houses`、`/houses/[id]`

参考 `05-houses.png`：

筛选：位置、户型、租金、排序。
卡片：图、标题、面积、朝向、楼层、位置、租金、标签、收藏、问小智，主体可进入详情。列表默认按所选位置的直线距离升序排列；每张卡展示“距您直线”，超过 10km 统一显示 `>10km`，不得冒充步行路线。
详情：历史字段、数据来源、周边、地图、预约演示，以及使用房源坐标生成的高德步行导航入口。

列表顶部提供互斥数据源页签：`2024 历史房源` 与 `近期租房线索`。近期线索独立请求、默认按共享位置的直线距离排序；价格可以显示为单值或区间。线索卡不复用演示预约，不缓存原帖图片；详情列出小红书/抖音 canonical 原帖链接、发布时间和“原帖未显示已结束”等来源状态，并始终显示 `房态未经核验`。

2024-11 历史数据目前只覆盖杭州；用户选择绍兴等未覆盖城市时必须明确说明不支持，不能返回杭州记录冒充当地房源。
近期租房线索首批同样只覆盖杭州。只有能定位到小区、明确地标或具体地铁站的记录才能展示距离；区县级粗坐标不得进入展示库。帖子区名与高德结果冲突时优先使用带行政区约束的 POI 搜索重新解析，仍冲突则进入人工复核并显示未核验边界。

## 我的 `/me`

参考 `09-profile.png`：

用户信息、收藏、浏览、订单、地址、对话历史、预算/区域/交通/饮食偏好、知识反馈、帮助设置。

## 知识反馈 `/me/feedback`

选择关联消息、错误类型、纠正建议和证据。提交到 `ai_feedback`，满足规则时创建候选知识。

## 知识运营 `/knowledge-admin`、`/knowledge-admin/[id]`

Demo Admin 专用：

- 候选列表
- 对话、当前知识、AI 草稿
- 审核、驳回、编辑、发布
- embedding 状态
- 回归评测结果

生产版本需独立后台和 RBAC。
