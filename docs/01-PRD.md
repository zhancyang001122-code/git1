# 小智本地生活 AI 服务助手 PRD

**版本：** 1.0  
**日期：** 2026-08-05  
**目标：** AI FDE / Solutions Engineer 作品集与面试演示

## 1. 背景

传统本地生活产品依赖多层筛选和跨页面跳转。用户的真实需求常是组合表达，例如“预算 3500、能养猫、离公司近、附近有超市”。普通搜索只能给列表，客服知识又与业务数据割裂。

小智以自然语言为统一入口，连接结构化业务查询、地图实时服务和客服知识检索，并用可解释的多步骤结果辅助决策。

## 2. 产品目标

### 用户目标

- 一句话完成找房、团购、买菜和周边搜索。
- 获得业务数据库和地图 API 的可核验结果。
- 获得带来源、版本和生效日期的规则回答。
- 在多轮对话中逐步补充条件，复用授权后的长期偏好。

### 面试目标

- 3 分钟内展示工具路由和多工具编排。
- 清楚区分 Mock 业务数据、实时 POI 和正式知识。
- 展示无依据拒答、低置信处理和知识审核发布。
- 能回答数据库、RAG、Function Calling、MCP、评测、安全和企业化问题。

## 3. 非目标与演示边界

保留界面入口和产品链路，但以下不作为真实生产交易：

- 支付、结算、发票
- 团购券真实核销
- 房屋签约、实名、租金托管
- 商家、房东、仓库完整后台
- 配送调度

必须显示“演示订单/模拟履约”，不能伪装成真实交易。

## 5. 用户故事与验收

### US-01 首页发现
用户可定位、搜索、浏览业务入口和精选卡片。首页搜索提交后进入小智并自动携带问题。

### US-02 社区推荐
用户浏览模拟分享卡片，按分类筛选，并把帖子上下文交给小智继续分析。

### US-03 结构化查询
模型提取条件，服务端查询 Supabase。3500 元以下、可养猫、一居室只能返回所有条件均满足且可用的房源。

### US-04 地图服务
用户搜索当前位置或固定地点附近 POI，查询步行距离。结果标注“高德地图”；路线失败时明确降级。

### US-05 知识问答
退款、押金、宠物、配送等问题通过正式知识库回答，显示标题、版本、生效日期、引用片段。低置信不得确定性回答。

### US-06 多工具组合
复杂问题可连续调用 Business、Maps、Knowledge 工具。UI 展示公开进度，调试面板展示工具、参数摘要、耗时和数据来源。

### US-07 用户偏好
用户可保存预算、宠物、区域、饮食、交通、家庭偏好。当前对话明确条件覆盖长期偏好。公共知识库不得保存个人偏好。

### US-08 知识进化
点赞、点踩、纠错、无结果、低置信、重复追问可生成知识候选。候选经过审核、发布、索引、评测后才能用于回答。

## 6. 页面功能

### 首页
定位、搜索、小智欢迎卡、租房/团购/超市/周边入口、附近精选、小智推荐横条。

### 推荐
双列卡片、分类、作者、位置、互动、收藏、“问问小智”、内容详情。

### 小智
欢迎页、快捷任务、流式对话、多轮上下文、工具进度、结构化卡片、知识引用、反馈、重试、调试面板。

### 消息
全部、系统、小智、互动；价格变化、券到期、小智推荐、社区互动、知识审核结果。

### 我的
收藏、浏览、演示订单、地址、对话历史、偏好、知识反馈、隐私和设置。

### 业务页
- 房源：位置、户型、租金、宠物、更多、排序、详情
- 团购：分类、距离、价格、折扣、销量、退款标签、详情
- 超市：商家、商品、库存、配送、购物车、配菜助手
- 周边：POI 分类、列表、距离、路线、问小智

## 7. AI 要求

- 工具调用最多 8 轮。
- 每轮写入 `ai_tool_runs`。
- 工具参数 Zod 校验；非法参数允许模型修复一次。
- 工具返回稳定 JSON，不暴露原始数据库错误。
- 最终文本流式输出，结构化卡片使用独立 SSE 事件。
- 对话采用“摘要 + 最近消息”，不无限携带全部历史。
- 同一工具相同参数单轮只执行一次。

## 8. RAG 要求

- 原始文章、版本、切片和向量分离。
- 状态：draft、reviewing、published、archived、rejected。
- 只检索 published 且当前有效版本。
- 向量召回 + 文本相似检索 + Metadata 过滤。
- 可选 `qwen3-rerank` 重排。
- 引用包含 article id、version id、chunk id、标题、版本、生效时间。
- 冲突知识转人工，不能让模型自行选政策。
- 评测检索命中、引用正确、忠实度、相关性、拒答准确性。

## 9. 数据来源

| 数据 | 来源 | 展示 |
|---|---|---|
| 房源、团购、商品、帖子 | Supabase Mock | 显示演示标识 |
| 收藏、偏好、对话 | Supabase | 真实交互 |
| 周边 POI、路线 | 高德 API | 显示来源 |
| 客服规则 | 自建知识库 | 标题、版本、生效日期 |
| 千问文本 | 生成层 | 不单独作为事实来源 |

## 10. 非功能要求

- 首页 LCP 目标 < 2.5s
- 普通业务查询 P95 < 2s
- AI 首文本 P95 < 4s
- 多工具任务 P95 < 15s，期间持续显示进度
- 360–430px 无横向滚动
- 桌面端以 430px 画布居中
- 超时、限流和网络错误有可恢复提示
- 基础键盘操作和可访问性

## 11. 演示指标

- 三条主演示链路成功率 100%
- 工具路由测试集准确率 ≥ 90%
- RAG 必答题引用正确率 ≥ 90%
- 无依据问题拒答准确率 ≥ 90%
- 页面和 AI 的同一业务数据一致率 100%

## 12. 实施阶段

1. 工程、设计系统和完整页面
2. Supabase 和基础 Agent
3. 高德与深入 RAG
4. 知识闭环、评测、安全和企业能力

完整需求保留，阶段只控制实现顺序。
