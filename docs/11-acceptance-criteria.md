# 验收标准

## P0 工程

- [ ] `web/` 可安装启动
- [ ] `pnpm lint`
- [ ] `pnpm typecheck`
- [ ] `pnpm test`
- [ ] `pnpm build`
- [ ] 核心 Playwright 通过

## P0 视觉

- [ ] 360/390/430px 无横向滚动
- [ ] 五主页面统一导航
- [ ] 顶部标题栏和右侧功能胶囊符合小程序式设计，按钮具有真实行为
- [ ] 底部五栏扁平等分，小智按钮不上浮
- [ ] 字号、圆角、边距符合 Token
- [ ] 桌面 430px 居中
- [ ] 不出现逐页尺寸漂移
- [ ] ActionSheet、Toast、确认弹窗覆盖键盘和可访问性状态
