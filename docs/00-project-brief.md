# 项目简报

## 一句话定位

小智是一款本地生活 AI 服务助手，通过自然语言连接房源、团购、线上超市、社区内容、地图服务和客服知识库，为用户完成“查找—比较—解释—继续行动”的任务。

## 面试价值

本项目展示 AI FDE 的五类能力：

1. 把模糊业务需求拆成可交付产品。
2. 区分结构化业务数据、外部实时数据和非结构化知识。
3. 通过 Function Calling 编排工具，而不是让模型自由编造。
4. 建立可引用、可版本化、可评测的 RAG。
5. 将知识缺口转为受控运营闭环，并设计企业级演进。

## 核心演示

> 帮我找武林广场附近 3500 元以内、可以养猫的一居室，步行 10 分钟内最好有超市，并告诉我宠物入住规则。

系统执行：

1. 解析地点、预算、户型、宠物和周边条件。
2. 从 Supabase 精确查询房源。
3. 通过高德查询附近超市和步行路线。
4. 通过 RAG 检索宠物规则并返回版本来源。
5. 综合排序，展示房源卡片、推荐理由、周边数据和知识引用。
